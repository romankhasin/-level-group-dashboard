# Автоматическое обновление дашборда

Workflow `.github/workflows/update-data.yml` запускается ежедневно в 06:00 по Москве и вручную через вкладку Actions.

Он обновляет:

- Яндекс Метрику по счётчикам `53197618` и `100470605`: с 1 мая 2026 года до вчерашнего дня, далее — только недостающие дни;
- показы, клики и стоимость Yandex/MTS из вкладки `Данные_метрика` по ключу `technical_mark`;
- `journal.html` из вкладки `Дневник оптимизации`, без фильтра по площадкам;
- Target Ads через Raw Data API v2 после появления секрета `TARGETADS_TOKEN`.

Обязательный Repository secret: `YANDEX_METRIKA_TOKEN`.

Необязательные Repository secrets: `TARGETADS_TOKEN` и `TARGETADS_PROJECT_ID`.
Если `TARGETADS_PROJECT_ID` не задан, используется прежнее значение `12787`.
Пока токена нет, остальные источники продолжают обновляться.

## Правило объединения Target Ads и Google

Для кампаний PRG Yandex/MTS Google является единственным источником показов, кликов
и стоимости. Для остальных площадок используются показы и клики из Target Ads.

Raw Data API v2 не передаёт GIVT/SIVT. В файле `data/targetads.json` эти совместимые
поля временно сохраняются со значением `0`; добавление фрод-метрик потребует отдельной
интеграции Fraud Reports API. Загрузчик валидирует токен, считывает справочник
размещений через Meta API и создаёт отдельные задания `Impression` и `Click` для
непересекающихся трёхдневных окон. Диагностический статус записывается в
`data/status.json`.
