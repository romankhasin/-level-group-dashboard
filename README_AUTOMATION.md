# Автоматическое обновление дашборда

Workflow `.github/workflows/update-data.yml` запускается ежедневно в 06:00 по Москве и вручную через вкладку Actions.

Он обновляет:

- Яндекс Метрику по счётчикам `53197618` и `100470605`: с 1 мая 2026 года до вчерашнего дня, далее — только недостающие дни;
- показы, клики и стоимость Yandex/MTS из вкладки `Данные_метрика` по ключу `technical_mark`;
- `journal.html` из вкладки `Дневник оптимизации`, без фильтра по площадкам;
- компактную стартовую сводку `data/latest-summary.json`; полные строки остаются
  в `data/latest.json` и загружаются дашбордом только по запросу пользователя.

Обязательный Repository secret: `YANDEX_METRIKA_TOKEN`.

История Target Ads за май–июль 2026 хранится в
`data/targetads_history_2026-05_2026-07.csv` и автоматически подключается при
открытии полного отчёта. Текущий незавершённый месяц загружается вручную в
интерфейсе и объединяется со встроенной историей по дате и technical_mark.
После закрытия месяца исторический файл нужно заменить расширенной выгрузкой и
обновить имя в `EMBEDDED_TARGETADS_HISTORY_URL`.

## Правило объединения Target Ads и Google

Для кампаний PRG Yandex/MTS Google является единственным источником показов, кликов
и стоимости. Для остальных площадок используются показы и клики из Target Ads.

Фрод-метрики Target Ads за май–июль подмешиваются из встроенной истории. Для
текущего месяца они добавляются ручным файлом в интерфейсе. Совпавшие строки
объединяются по дате и technical_mark без повторного сложения показов и кликов.
